wartezi.de – Open Source Aufrufsystem für die Praxis

Patientenaufruf per GDT
Vollständig offline. Vollständig isoliert. Open Source.

GitHub Dokumentation
Läuft mit T2med, x.concept, tomedo und vermutlich fast allen anderen Praxisverwaltungssystemen (PVS).
▶ Installation
wget https://fragebogenpi.de/wartezi.sh
chmod +x wartezi.sh
sudo bash wartezi.sh
Man benötigt
  • Raspberry Pi ab Version 4
  • Raspberry Pi OS (Lite empfohlen)
  • High-Endurance-SD-Karte
  • WLAN z.B. abgeschottet zu fragebogenpi oder LAN-Anschluss

Ablauf

  1. Patientendaten per GDT an den Monitor
  2. (Landschafts) Video unterbricht, Ding-Dong
  3. Patientenname wird Angezeit (auf Wunsch abgekürzt)
